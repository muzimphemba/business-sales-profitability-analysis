# Business Sales & Profitability Analysis

## Project Overview
This project analyses business sales and profitability data to identify
trends, evaluate product performance, and support data-driven decisions.

## Objectives
- Analyse sales and profit performance.
- Identify the strongest-performing products and segments.
- Explore trends across time and countries.
- Develop evidence-based business recommendations.

## Tools
- Microsoft Excel
- SQL
- Microsoft Power BI

## Dataset
Source: Microsoft Financial Sample

https://learn.microsoft.com/en-us/power-bi/create-reports/sample-financial-download

## Project Workflow
1. Data understanding and quality checks
2. Data cleaning and preparation
3. Exploratory data analysis
4. SQL queries and KPI calculations
5. Power BI dashboard development
6. Findings and recommendations
